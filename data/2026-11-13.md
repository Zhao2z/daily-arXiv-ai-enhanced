TL;DR: 本文报告了对Claude Code在生产消息派发引擎中诊断八起数据库故障的实地观察：凡是根因依赖运行时并发的故障，该智能体都先宣布原因、提交修复、而后又撤回；生产状态访问缺失是最普遍的瓶颈，作者据此提出构建"取证层"。

Motivation: LLM编码智能体正被要求基于实时运行时数据调试运行中的系统，但已有工作缺乏对真实生产环境下智能体失败模式的实证理解，尤其是并发类故障这一难点。

Method: 在生产消息派发引擎中对单个LLM编码智能体（Claude Code）进行实地观察，让其一一线诊断八起数据库故障，并把每起故障映射到智能体所欠缺的能力，以定位瓶颈类别。

Result: 五起依赖并发的故障全部出现错误猜测与修复撤回，每次错误都付出一次"部署—观察"周期代价。访问缺口在所有五起并发故障中都存在：一起为唯一原因，另四起与推理错误（过早锚定、配置探索不全、误读事务语义）叠加。三起非并发故障无需额外能力即可解决。错误假设均与其可见证据一致，并非凭空捏造。

Conclusion: 生产状态访问缺失是最普遍瓶颈（实时锁视图、未截断的死锁报告、只读执行、显式环境上下文）。作者主张下一阶段应构建位于现有安全控制之内的"取证层"，包含安全询问API、锁与死锁"飞行记录仪"及生产回放装置。

Abstract: Large language model (LLM) coding agents are increasingly asked not only to write code but to debug running systems from live runtime data. We report a field observation of one such agent (Claude Code) as it diagnosed eight database incidents in a production message-dispatch engine. In every incident whose root cause depended on runtime concurrency, the agent announced a cause, shipped a fix, and later walked it back, and each wrong guess cost a deploy-and-observe cycle. Mapping each incident to what the agent lacked, we find that access to production state was the most pervasive bottleneck. The missing access included live lock views, untruncated deadlock reports, read-only execution, and an explicit environment context. An access gap was present in all five concurrency-dependent incidents: alone in one, and in four combined with a reasoning error such as anchoring on an early cause, incomplete exploration of the configuration, or a misreading of the code's transaction semantics. The three incidents that did not depend on concurrency needed nothing beyond what the agent already had. Within the incidents, the agent's wrong hypotheses were consistent with the evidence it could see; they were not fabrications. We argue that the next step for production-debugging agents is a forensics layer that gives the agent the access it lacks inside existing security controls. Such a layer would combine a safe interrogation API, a lock-and-deadlock flight recorder, and a production replay harness.
