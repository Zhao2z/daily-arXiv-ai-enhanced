### [1] [Agentic AI Containment Architecture for Security Hardening](https://arxiv.org/abs/2608.26108)
*Mohamed ElBendary*

Main category: cs.SE

TL;DR: 本文提出了一种Agent遏制架构（Agent Containment Architecture），将安全性作为多智能体系统的架构属性而非事后附加层，通过六种交互约束强制实施Propose-Verify-Act-Verify执行模型，使所有操作合约化定义、独立验证并可追溯。

Motivation: 多智能体AI系统在自主协调、工具使用和持续学习中面临新的安全与治理风险，但现有遏制方法主要在系统设计和部署后添加防护层，缺乏将安全作为内建架构属性的系统性方法。

Method: 提出一种Agent遏制架构，包含六种交互约束：职责分配分离、部署前一致性检查、价值流绑定、时间隔离、严格知识验证与积累、结构与过程完整性的确定性验证。通过正式的组织映射将标准系统分析工件转化为机器可验证合约，强制实施Propose-Verify-Act-Verify执行模型。

Result: 通过命题和正确性推理论证，证明这些约束能防御关键威胁类别（提示注入、编排器操纵、跨会话状态投毒、新兴智能体共谋）。简历筛选案例研究展示了该架构在对抗条件下产生可审计、符合策略的结果。工作明确区分了结构完整性与语义安全性，使残余语义风险显式且可度量。

Conclusion: 该架构证明了多智能体系统安全可通过架构层面的显式约束来实现，将残余风险限定在明确范围内，同时让语义层面的残余风险变得可见和可量化，为多智能体系统安全治理提供了新范式。

Abstract: Multi-agent AI systems are increasingly deployed in contexts where autonomous coordination, tool use, and continuous learning introduce novel security and governance risks. The containment approach to multi-agent system security remains underdeveloped, primarily resorting to add-on layers post-design and sometimes post-implementation and deployment. This paper proposes an Agent Containment Architecture that treats security as an architectural property enforced through a set of explicit constraints that bound the design space of multi-agent systems. The architecture proposed in this paper introduces a novel formal organizational mapping from standard systems analysis artifacts to machine-verifiable contracts under a proposed constraint system. The architecture introduces six interacting constraints: separation of responsibility assignments, pre-deployment coherence checking, value stream binding, temporal isolation, strict knowledge verification before accumulation, and deterministic verification of structural and process integrity. Together, these constraints enforce a Propose-Verify-Act-Verify execution model in which all operations are contractually defined, independently verified, and traceable to specific execution contexts. The paper presents propositions and correctness reasoning arguments linking these constraints to defenses against key threat classes, including prompt injection, orchestrator manipulation, cross-session state poisoning, and emergent agent collusion. A resume screening case study demonstrates how the architecture produces auditable, policy-compliant outcomes under adversarial conditions. The work explicitly separates structural integrity from semantic safety, bounding residual risks while making residual semantic risk explicit and measurable.
