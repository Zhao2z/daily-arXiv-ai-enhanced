### [1] [Trace2ST: Recovering PLC Structured Text from I/O Traces with LLM Generation and Verification](https://arxiv.org/abs/2611.24979)
*Hsi Chang,Irfan Khan*

<details>
  <summary>Details</summary>
Motivation: 工业PLC程序常因源代码丢失而无法维护，但控制器所有I/O均被持续记录。核心问题是：LLM能否仅从I/O轨迹恢复可执行ST程序，且如何验证恢复程序的正确性。

Abstract: Programmable logic controllers (PLCs), the industrial computers that operate power and process plants, often run programs whose source code is no longer available; however, every input and output of the controller is logged continuously.
